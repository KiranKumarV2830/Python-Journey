## 📖 About

Day 18 focuses on **Tuples**, a Python collection used to store multiple values in a single variable.

Tuples are **ordered and immutable**, which means their elements can be accessed using indexes but cannot be changed after creation.

## 🎯 Topics Covered

- Tuple Creation
- Tuple Indexing
- Negative Indexing
- Tuple Slicing
- `len()`
- `count()`
- `index()`
- Tuple Unpacking
- Looping Through Tuples
- Tuple Immutability
- List vs Tuple

## 🚀 Goal

Understand how tuples work and when to use them instead of lists.
