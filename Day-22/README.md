## 📖 About

Day 22 focuses on **Exception Handling**, which allows Python programs to handle errors without crashing.

The main focus is learning how to use `try` and `except` to safely handle invalid input and common runtime errors.

## 🎯 Topics Covered

- Exceptions
- `try`
- `except`
- `ValueError`
- `ZeroDivisionError`
- `FileNotFoundError`
- `FileExistsError`
- Handling Invalid Input
- Preventing Program Crashes
- Multiple `except` Blocks
- Basic Error Handling

## 🚀 Goal

Learn how to identify and handle common exceptions so that programs can continue running safely.
