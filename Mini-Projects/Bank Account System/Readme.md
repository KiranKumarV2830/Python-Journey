# 🏦 Bank Account System

A simple Python mini project that demonstrates the use of **Local Variables**, **Global Variables**, **Functions**, and the **global keyword**.

---

# 📖 About

This project simulates a basic bank account where users can:

- View account details
- Check current balance
- Deposit money
- Withdraw money
- Update the account balance

This project was created while learning **Variable Scope** in Python.

---

# 📚 Concepts Used

- Functions
- Local Variables
- Global Variables
- global Keyword
- Function Calls
- Variables
- User Input
- Arithmetic Operators
- If-Else Statements

---

# 🚀 Features

✅ Display Bank Name
