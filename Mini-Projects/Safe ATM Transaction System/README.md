# 🏧 Safe ATM Transaction System

## 📖 About

The **Safe ATM Transaction System** is a Python mini project designed to practice **exception handling, input validation, conditional statements, loops, and match-case**.

The program simulates basic ATM operations while safely handling invalid user input and transaction errors.

## 🎯 Concepts Used

- `try`
- `except`
- `ValueError`
- `if-elif-else`
- `match-case`
- `while` Loop
- `break`
- User Input
- Input Validation
- Variables
- Arithmetic Operators
- Balance Management

## 🚀 Features

- 🔐 PIN Verification
- 💰 Check Balance
- 💸 Withdraw Money
- ➕ Deposit Money
- ⚠️ Invalid Input Handling
- 🚫 Insufficient Balance Checking
- 🔢 Positive Amount Validation
- 🚪 Exit Option
- 🛡️ Exception Handling

## 🧠 What I Practiced

This project helped me understand how **exception handling** can be combined with validation and control flow to prevent a program from crashing when users enter invalid data.
