# 📖 About the Project

The **Shopping Cart Manager** allows a user to manage items in a shopping cart through a simple menu.

The user can:

1. Add an item
2. Remove an item
3. View the cart
4. Sort the cart
5. Clear the cart
6. Exit the program

This project combines concepts I learned in previous days with the new **List Methods** learned on Day 16.
