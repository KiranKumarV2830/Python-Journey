# 🎓 Student Course Registration Manager

## 📖 About

The **Student Course Registration Manager** is a Python mini project designed to practice managing student and course information using Python collections.

The project focuses on storing student details, registering courses, and working with structured data.

## 🎯 Concepts Used

- Dictionaries
- Lists
- Tuples
- Loops
- `if-else`
- `match-case`
- User Input
- Data Validation
- Adding Data
- Removing Data
- Searching Data

## 🚀 Features

- 👨‍🎓 Store student information
- 📚 Display available courses
- 📝 Register students for courses
- 🔍 Search student information
- 📋 Display registered courses
- ❌ Remove course registration
- ⚠️ Handle invalid choices
- 🔄 Manage multiple registrations

## 🧠 What I Practiced

This project helped me understand how to organize and manage related information using **Python collections and control flow**.
