# 🎓 Student Marks Dictionary

## 📖 About

The **Student Marks Dictionary** is a Python mini project designed to practice using **dictionaries and lists to store and manage student marks**.

The project stores each student's name as a key and their marks as a list of values.

## 🎯 Concepts Used

- Dictionaries
- Lists
- Key-Value Pairs
- `.items()`
- `.values()`
- List Indexing
- `for` Loops
- Nested Loops
- Total Calculation
- Average Calculation
- Highest Marks
- Lowest Marks
- Pass/Fail Checking

## 🚀 Features

- 👨‍🎓 Store student names
- 📚 Store multiple marks for each student
- 📊 Display student names and marks
- ➕ Calculate total marks
- 📈 Calculate average marks
- 🏆 Find highest marks
- 📉 Find lowest marks
- ✅ Check pass/fail status
- 🔄 Process multiple students

## 🧠 What I Practiced

This project helped me understand how to work with **dictionaries containing lists** and how to use **nested loops** to process multiple marks for different students.

I also practiced calculating totals, averages, highest and lowest marks, and checking whether students passed or failed.
