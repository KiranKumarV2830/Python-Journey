# 🎓 Student Performance Tracker

## 📖 About

The **Student Performance Tracker** is a Python mini project designed to practice working with **dictionaries, lists, loops, conditions, totals, averages, highest and lowest marks, and pass/fail calculations**.

The program stores student names and their marks and analyzes their academic performance.

## 🎯 Concepts Used

- Dictionaries
- Lists
- Nested Loops
- `for` Loops
- `if-else`
- `len()`
- `sum` logic
- Total Calculation
- Average Calculation
- Highest Marks
- Lowest Marks
- Pass/Fail Checking
- Input Processing

## 🚀 Features

- 👨‍🎓 Store student names and marks
- 📊 Display student marks
- ➕ Calculate total marks
- 📈 Calculate average marks
- 🏆 Find highest marks
- 📉 Find lowest marks
- ✅ Check pass/fail status
- 🔄 Process multiple students

## 🧠 What I Practiced

This project helped me understand how to work with **nested data structures** and how to use loops to process marks stored inside a dictionary.
