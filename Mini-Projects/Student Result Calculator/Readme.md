# 🎓 Student Result Calculator

A beginner-friendly Python mini project that calculates a student's total marks, percentage, and grade using functions and return statements.

---

# 📚 Concepts Practiced

- Functions
- Parameters
- Return Statement
- Function Calls
- Conditional Statements
- Arithmetic Operations

---

# 📂 Features

- Enter Student Name
- Enter Marks
- Calculate Total Marks
- Calculate Percentage
- Assign Grade
- Display Final Result

---

# 🛠 Functions Used

```python
total_marks(m1, m2, m3)
percentage(total)
grade(percent)
result(name, grade)
```
