# 🧠 How I'm Learning

Each day follows the same structure:

1. **Concept** — definitions and code examples for every subtopic
2. **Practice Questions** — hands-on problems to lock in the concept
3. **Interview Questions** — theory questions asked out loud, like a real interview
4. **Mini Project** — a small working program combining everything from that day

This keeps learning consistent, practical, and portfolio-ready from Day 1.
